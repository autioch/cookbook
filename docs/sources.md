# Sources

What each source gave the site. A recipe names its sources on its page (`sources` in the recipe
file); this list says what was taken. Every text is written fresh, never copied.

one page the family picked, rewritten fresh; no amount added where the page has none. Servings
"estimated" means the page gave none and the schema needs a number. The family corrects them once
cooked.
