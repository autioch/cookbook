title: Prażonki
summary: 'Ziemniaki z kiełbasą, boczkiem i cebulą, warstwami w żeliwnym kociołku, prażone na ognisku albo w piekarniku. Na dużą rodzinę.'
categories: [obiad]
status: szkic
servings: 10
time: { active: 30, total: 90 }
ingredients:
  - items:
      - { name: ziemniaki, amount: 4, unit: kg }
      - { name: kiełbasa, amount: 1, unit: kg }
      - { name: boczek wędzony, amount: 500, unit: g, product: boczek }
      - { name: cebula, amount: 5, note: duże }
      - { name: kapusta biała, amount: 3, unit: liście, note: duże, product: kapusta }
      - { name: smalec, amount: 2, unit: łyżki }
      - { name: sól }
      - { name: pieprz }
steps:
  - items:
      - Pokrój ziemniaki w grube plastry albo półplastry, kiełbasę w kostkę, boczek w słupki, cebulę w plastry.
      - 'Układaj w kociołku cienkie warstwy: ziemniaki, sól i pieprz, kiełbasa, znów ziemniaki z solą i pieprzem, boczek. Powtarzaj, aż skończą się składniki.'
      - Na wierzch połóż cebulę i przykryj liśćmi kapusty.
      - Zamknij szczelnie kociołek i postaw na ognisku na ok. 60 minut. W piekarniku piecz w 180 °C 45–50 minut.
