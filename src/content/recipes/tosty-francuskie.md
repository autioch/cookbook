---
title: Tosty francuskie
summary: 'Chleb w jajku z mlekiem, smażony na maśle. Na słodko z cukrem pudrem i owocami albo na słono.'
categories: [sniadanie, kolacja]
status: szkic
servings: 2
time: { active: 15, total: 15 }
spice: 0
ingredients:
  - items:
      - { name: chleb, amount: 6, unit: kromek, note: 'najlepiej czerstwy, z wczoraj' }
      - { name: jajka, amount: 3 }
      - { name: mleko, amount: 120, unit: ml }
      - { name: masło, amount: 2, unit: łyżki }
      - { name: sól, amount: 1, unit: szczypta }
  - title: Na słodko
    items:
      - { name: cynamon, amount: 0.5, unit: łyżeczki, optional: true }
      - { name: cukier puder, note: do posypania, optional: true }
      - { name: owoce, note: na przykład truskawki albo banan, optional: true }
steps:
  - items:
      - W głębokim talerzu roztrzep jajka z mlekiem i solą. Na słodko dodaj cynamon.
      - Rozgrzej łyżkę masła na patelni na średnim ogniu.
      - Zanurz kromkę w jajku na kilka sekund z każdej strony, żeby nasiąkła, ale się nie rozpadła.
      - Smaż po 2–3 minuty z każdej strony, aż będzie złota. Dokładaj masło przed każdą partią.
      - Podawaj od razu, na słodko z cukrem pudrem i owocami.

Świeży chleb rozmięka w jajku. Jeśli nie ma czerstwego, kromki można podsuszyć kilka minut w
piekarniku.
