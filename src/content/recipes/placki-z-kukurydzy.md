title: Placki z kukurydzy (bakwan jagung)
summary: 'Indonezyjskie placuszki z kukurydzy, szczypiorku i szalotek, smażone na patelni. Ze słodkim sosem sojowym i ostrym sosem chili.'
categories: [przekaska, kolacja]
status: szkic
servings: 4
time: { active: 30, total: 30 }
ingredients:
  - title: Placki
    items:
      - { name: kukurydza, amount: 340, unit: g, note: 'z puszki albo z 2–3 ugotowanych kolb' }
      - { name: mąka pszenna, amount: 150, unit: g, product: mąka }
      - { name: mąka ryżowa, amount: 75, unit: g }
      - { name: jajka, amount: 3 }
      - { name: szczypiorek, amount: 0.5, unit: pęczka }
      - { name: szalotki, amount: 5, note: 'do 7, albo 1 cebula', product: cebula }
      - { name: czosnek, amount: 5, unit: ząbków, note: albo mniej }
      - { name: woda, amount: 150, unit: ml, note: '100–200 ml, ile trzeba' }
      - { name: sól, amount: 0.5, unit: łyżeczki }
      - { name: pieprz, amount: 0.5, unit: łyżeczki }
      - { name: olej, note: do smażenia }
  - title: Do podania
    items:
      - { name: słodki sos sojowy (kecap manis), product: sos sojowy, optional: true }
      - { name: ostry sos chili (sambal), product: sos chili, optional: true }
steps:
  - items:
      - Drobno pokrój szalotki i czosnek, posiekaj szczypiorek.
      - W dużej misce wymieszaj wszystkie składniki placków oprócz wody i oleju.
      - Dolewaj wodę po trochu, tylko tyle, ile trzeba. Masa ma być gęsta i ledwo się rozlewać.
      - Rozgrzej olej na patelni. Nakładaj po 1–1,5 łyżki masy, formuj placki i smaż z obu stron na złoto.
      - Odsącz na ręczniku papierowym. Podawaj na gorąco, posmarowane słodkim sosem sojowym, z ostrym sosem chili obok.
