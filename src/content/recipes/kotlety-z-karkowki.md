title: Kotlety z karkówki z majerankiem
summary: 'Rozbite plastry karkówki natarte czosnkiem i majerankiem, smażone na patelni. Z ziemniakami i surówką.'
categories: [obiad]
status: szkic
servings: 3
time: { active: 30, total: 90 }
ingredients:
  - items:
      - { name: karkówka, amount: 500, unit: g }
      - { name: czosnek, amount: 1, unit: główka, note: mała }
      - { name: majeranek, amount: 4, unit: łyżki }
      - { name: olej, amount: 100, unit: ml, note: do marynaty i smażenia }
      - { name: sól }
      - { name: pieprz }
steps:
  - items:
      - Pokrój karkówkę w plastry grubości 1 cm i rozbij je lekko z obu stron.
      - Obierz czosnek i przeciśnij przez praskę albo rozetrzyj z solą.
      - Posól każdy plaster, natrzyj czosnkiem, popieprz i posyp majerankiem. Ułóż w misce, zalej olejem, przykryj i wstaw na godzinę do lodówki. Marynowanie można pominąć.
      - Rozgrzej patelnię i smaż kotlety partiami po kilka minut z każdej strony, aż się zrumienią. Podawaj z ziemniakami i surówką.
