title: Schabowy z ziemniakami i mizerią

categories: [obiad]
status: szkic
servings: 4
time: { active: 50, total: 60 }
spice: 0
ingredients:
  - title: Kotlety
    items:
      - {
          name: schab bez kości,
          amount: 600,
          unit: g,
          note: '4 plastry po ok. 1,5 cm',
          product: schab,
        }
      - { name: jajka, amount: 2 }
      - { name: mąka pszenna, amount: 3, unit: łyżki, product: mąka }
      - { name: bułka tarta, amount: 100, unit: g }
      - { name: smalec albo olej do smażenia, amount: 100, unit: g, product: olej }
      - { name: sól }
      - { name: pieprz }
  - title: Ziemniaki
    items:
      - { name: ziemniaki, amount: 1, unit: kg }
      - { name: masło, amount: 1, unit: łyżka }
      - { name: koperek, amount: 0.5, unit: pęczka }
      - { name: sól }
  - title: Mizeria
    items:
      - { name: ogórki gruntowe, amount: 3, note: albo 1 długi szklarniowy, product: ogórki }
      - { name: śmietana 18 %, amount: 150, unit: g, product: śmietana }
      - { name: koperek, amount: 0.5, unit: pęczka }
      - { name: sok z cytryny, amount: 1, unit: łyżeczka, product: cytryna }
      - { name: sól }
      - { name: pieprz }
steps:
  - title: Ziemniaki
    items:
      - Obierz ziemniaki, pokrój duże na pół i zalej zimną, osoloną wodą.
      - Gotuj ok. 20 minut od zagotowania, aż nóż wchodzi bez oporu. Odcedź, dodaj masło i posiekany koperek.
  - title: Mizeria
    items:
      - Obierz ogórki i pokrój w cienkie plasterki. Posól, odstaw na 10 minut i odlej sok.
      - Wymieszaj ze śmietaną, koperkiem i sokiem z cytryny. Dopraw pieprzem.
  - title: Kotlety
    items:
      - Rozbij plastry schabu tłuczkiem przez folię na grubość ok. 0,5 cm. Posól i popieprz z obu stron.
      - Na trzy talerze daj mąkę, roztrzepane jajka i bułkę tartą. Obtocz każdy kotlet po kolei w mące, jajku i bułce.
      - Rozgrzej tłuszcz na patelni. Smaż kotlety na średnim ogniu po 3–4 minuty z każdej strony, aż będą złote.
      - Odłóż na ręcznik papierowy, żeby odsączyć tłuszcz. Podawaj od razu z ziemniakami i mizerią.
