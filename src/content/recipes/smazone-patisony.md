---
title: Smażone patisony
summary: 'Plastry patisona natarte czosnkiem, w panierce z mąki, jajka i bułki tartej, smażone na złoto. Z sałatą i sosem tatarskim.'
categories: [obiad, przekaska]
status: szkic
servings: 2
time: { active: 25, total: 40 }
ingredients:
  - items:
      - { name: patison, amount: 1, note: średni }
      - { name: czosnek, amount: 2, unit: ząbki }
      - { name: przyprawa warzywna, note: w proszku }
      - { name: pieprz }
      - { name: mąka pszenna, note: do panierki, product: mąka }
      - { name: jajko, amount: 1, product: jajka }
      - { name: mleko, note: 'odrobina, do jajka' }
      - { name: bułka tarta }
      - { name: olej, note: do smażenia }
      - { name: sos tatarski, note: do podania, optional: true }
steps:
  - items:
      - Obierz patisona (młodego nie trzeba). Pokrój w plastry grubości 1 cm i wytnij gniazda nasienne.
      - Natrzyj plastry przeciśniętym czosnkiem, posyp przyprawą i pieprzem. Odstaw na kwadrans.
      - Obtaczaj po kolei w mące, w jajku roztrzepanym z mlekiem i w bułce tartej.
      - Smaż na mocno rozgrzanym oleju, aż będą złote. Przykryj patelnię i smaż jeszcze chwilę na bardzo małym ogniu, żeby zmiękły.
      - Odsącz na ręczniku papierowym. Podawaj na sałacie, z sosem tatarskim albo jogurtowym.
sources:
