---
title: Ciasto bananowe
summary: 'Ciasto z bardzo dojrzałych bananów, mieszane łyżką, pieczone w keksówce.'
categories: [deser]
status: szkic
servings: 10
time: { active: 5, total: 60 }
ingredients:
  - items:
      - { name: banany, amount: 4, note: bardzo dojrzałe }
      - { name: cukier, amount: 100, unit: g, note: 'do 150 g, jeśli wolisz słodsze' }
      - { name: mąka pszenna tortowa, amount: 240, unit: g, note: '1,5 szklanki', product: mąka }
      - { name: soda oczyszczona, amount: 1, unit: łyżeczka }
      - { name: jajko, amount: 1, product: jajka }
      - { name: masło, amount: 50, unit: g, note: roztopione i przestudzone }
      - { name: bakalie, amount: 100, unit: g, note: 'orzechy, rodzynki' }
      - { name: cukier puder, note: do posypania, optional: true }
steps:
  - items:
      - Nagrzej piekarnik do 175 °C, grzanie góra-dół. Wyłóż keksówkę papierem albo wysmaruj masłem i posyp bułką tartą.
      - Przesiej mąkę z sodą do miski.
      - W drugiej misce rozgnieć banany widelcem i wymieszaj z cukrem.
      - Dodaj jajko, masło, mąkę z sodą i bakalie. Wymieszaj dużą łyżką, tylko do połączenia.
      - Przełóż ciasto do keksówki i natnij wierzch nożem wzdłuż środka, tam ciasto ładnie pęknie.
      - Piecz ok. 55 minut, aż patyczek wbity w środek wyjdzie suchy. Wystudzone możesz posypać cukrem pudrem.
