---
title: Chlebek turecki
summary: 'Ciemny, słodkawy chlebek drożdżowy z melasą, kawą zbożową i rodzynkami. Z jednego ciasta dwa bochenki albo 12 bułek.'
categories: [sniadanie, kolacja]
status: szkic
servings: 12
time: { active: 30, total: 190 }
ingredients:
  - title: Ciasto
    items:
      - { name: mąka pszenna chlebowa, amount: 500, unit: g, product: mąka }
      - { name: drożdże suche, amount: 7, unit: g, note: 'albo 14 g świeżych', product: drożdże }
      - { name: mleko, amount: 330, unit: ml }
      - { name: masło, amount: 40, unit: g, note: roztopione i przestudzone }
      - { name: melasa, note: '⅓ szklanki' }
      - { name: kawa zbożowa, amount: 4, unit: łyżeczki }
      - { name: rodzynki, amount: 100, unit: g }
      - { name: sól, amount: 1, unit: łyżeczka }
      - { name: cukier brązowy, amount: 1, unit: łyżeczka, product: cukier, optional: true }
  - title: Do posmarowania
    items:
      - { name: jajko, amount: 1, product: jajka }
      - { name: mleko, amount: 1, unit: łyżka }
steps:
  - title: Ciasto
    items:
      - Wyjmij wszystko z lodówki wcześniej, żeby składniki miały temperaturę pokojową.
      - Podgrzej mleko i rozpuść w nim melasę. Przestudź, aż będzie tylko letnie.
      - Wymieszaj mąkę z suchymi drożdżami. Świeże drożdże rozpuść najpierw w części mleka.
      - Dodaj mleko z melasą, kawę zbożową, sól i cukier. Wyrabiaj, pod koniec dolej roztopione masło. Ciasto ma być miękkie i elastyczne.
      - Wmieszaj rodzynki i wyrób krótko jeszcze raz.
      - Włóż ciasto do miski oprószonej mąką, przykryj ściereczką i odstaw w ciepłe miejsce na ok. 1,5 godziny, aż podwoi objętość.
  - title: Formowanie i pieczenie
    items:
      - Podziel ciasto na pół i uformuj dwa bochenki. Przełóż do dwóch keksówek 10 × 20 cm, wysmarowanych masłem i oprószonych mąką. Na bułki odrywaj kawałki po ok. 80 g i formuj kulki.
      - Odstaw na 30–40 minut, aż znów podwoją objętość.
      - Roztrzep jajko z łyżką mleka i posmaruj wierzch.
      - Piecz w 190 °C, chlebki ok. 30 minut, bułki ok. 20 minut. Wystudź na kratce.

Źródło podaje też sposób dla maszyny do chleba: wszystkie składniki do maszyny (najpierw płynne,
potem sypkie, na końcu drożdże), program do wyrabiania ciasta, potem formowanie jak wyżej.
