categories: [obiad, kolacja]

servings: 3

ingredients:
  - items:
      - {
          name: krewetki surowe,
          amount: 500,
          unit: g,
          note: 'świeże albo mrożone, szare',
          product: krewetki,
        }
      - { name: masło, amount: 3, unit: łyżki }
      - { name: oliwa, amount: 2, unit: łyżki }
      - { name: czosnek, amount: 3, unit: ząbki }
      - {
          name: białe wino wytrawne,
          amount: 100,
          unit: ml,
          note: 'trochę ponad ⅓ szklanki',
          product: białe wino,
        }
      - { name: cytryna, amount: 0.5, note: 'skórka otarta i 1 łyżka soku' }
      - { name: natka pietruszki, amount: 4, unit: łyżki, note: posiekana }
      - { name: płatki chili, amount: 1, unit: szczypta, product: chili, optional: true }
      - { name: sól }
      - { name: pieprz }
      - { name: makaron albo bagietka, note: do podania, product: makaron }
steps:
  - items:
      - Mrożone krewetki rozmroź wcześniej, przez noc w lodówce.
      - Umyj i osusz krewetki, obierz je z pancerzy i odnóży. Natnij wzdłuż grzbietu i wyjmij ciemną nitkę. Ogonki możesz zostawić.
      - Sparz cytrynę wrzątkiem i zetrzyj skórkę z połowy. Obierz i drobno posiekaj czosnek.
      - Na dużej patelni rozgrzej masło z oliwą, chili, skórką cytryny i szczyptą soli.
      - Kiedy masło się rozpuści, wrzuć czosnek. Po ok. 10 sekundach dodaj krewetki i rozłóż je równo.
      - Wlej wino i łyżkę soku z cytryny. Gotuj ok. 2 minuty, odwróć krewetki i gotuj jeszcze minutę.
      - Wmieszaj natkę i zdejmij z ognia. Popieprz i podawaj od razu, wymieszane z makaronem albo z pieczywem do maczania.
