title: Baklawa
summary: 'Warstwy ciasta filo z masłem i orzechami, krojone przed pieczeniem i zalane syropem z miodem. Musi odstać kilka godzin.'

  - title: Ciasto i nadzienie

      - { name: masło klarowane, amount: 150, unit: g }
      - { name: pistacje albo orzechy włoskie, amount: 200, unit: g, product: orzechy }
      - { name: cynamon, amount: 0.5, unit: łyżeczki }
  - title: Syrop
    items:

      - { name: sok z cytryny, amount: 1, unit: łyżka, product: cytryna }
      - { name: woda różana, amount: 1, unit: łyżka, note: 'do 2, do syropu', optional: true }
steps:
  - title: Składanie i pieczenie
    items:
      - Posiekaj orzechy grubo i wymieszaj z cynamonem. Rozpuść masło na małym ogniu, aż będzie przezroczyste i lekko złote.
      - Nagrzej piekarnik do 170 °C, grzanie góra-dół. Natłuść formę 20 × 30 cm.
      - Rozwiń filo i przykryj wilgotną ściereczką, bo szybko wysycha. Przytnij arkusze do formy.
      - Ułóż 6–8 arkuszy, każdy smarując cienko masłem. Wysyp połowę orzechów.
      - Ułóż 5 arkuszy z masłem, potem resztę orzechów, na koniec 6–8 arkuszy, każdy smarując.
      - Pokrój surową baklawę ostrym nożem w romby albo kwadraty, tak żeby nie przesunąć warstw. Po upieczeniu ciasto byłoby za kruche do krojenia.
      - Piecz 45–50 minut, aż będzie złotobrązowa. Jeśli wierzch za mocno się rumieni, po 30 minutach przykryj folią.
  - title: Syrop
    items:
      - W czasie pieczenia zagotuj wodę z cukrem, miodem i sokiem z cytryny. Gotuj na małym ogniu 10–12 minut, aż lekko zgęstnieje.
      - Zdejmij z ognia i ostudź.
      - Gorącą baklawę zaraz po wyjęciu z piekarnika polej powoli i równo zimnym syropem.
      - Zostaw na co najmniej 4 godziny, najlepiej na noc, żeby syrop się wchłonął.
