      - { name: śmietana 18 %, amount: 150, unit: g, product: śmietana }
      - { name: makaron nitki, amount: 200, unit: g, note: albo ryż, product: makaron }
      - { name: natka pietruszki, amount: 2, unit: łyżki, note: posiekana, optional: true }

steps:
  - items:
      - Zagotuj rosół. Wlej przecier, wymieszaj i gotuj na małym ogniu 10 minut.
      - Makaron ugotuj osobno w osolonej wodzie, według opisu na opakowaniu, i odcedź.
      - Śmietanę wymieszaj w kubku z kilkoma łyżkami gorącej zupy, żeby się nie zważyła. Wlej do garnka i już nie gotuj.
      - Spróbuj. Dopraw solą i pieprzem, a gdy zupa jest za kwaśna, szczyptą cukru.
      - Nałóż makaron do talerzy, zalej zupą i posyp natką.
