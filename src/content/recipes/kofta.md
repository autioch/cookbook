title: Kofta
summary: 'Podłużne szaszłyki z mielonego mięsa z czosnkiem, imbirem i przyprawami, z grilla, patelni albo piekarnika. Z pitą i sosem jogurtowym.'
categories: [obiad, kolacja]
status: szkic
servings: 6
time: { active: 20, total: 40 }
spice: 1
ingredients:
  - items:
      - { name: mięso mielone, amount: 600, unit: g, note: 'wołowina, jagnięcina albo pół na pół' }
      - { name: cebula, amount: 0.5, note: mała }
      - { name: czosnek, amount: 4, unit: ząbki }
      - { name: imbir świeży, note: 'kawałek 3 cm', product: imbir }
      - { name: natka pietruszki, note: garść }
      - { name: kolendra mielona, amount: 1, unit: łyżeczka, product: kolendra }
      - { name: papryka słodka, amount: 1, unit: łyżeczka }
      - { name: papryka ostra, amount: 0.5, unit: łyżeczki }
      - { name: cynamon, note: '⅓ łyżeczki' }
      - { name: kumin, note: '⅓ łyżeczki, kmin rzymski' }
      - { name: sól, amount: 1, unit: łyżeczka }
      - { name: pieprz, amount: 0.5, unit: łyżeczki }
      - { name: olej, amount: 1, unit: łyżka }
      - { name: pita albo naan, note: do podania, product: pity, optional: true }
steps:
  - items:
      - Namocz drewniane patyczki do szaszłyków w zimnej wodzie, żeby się nie przypaliły.
      - Obierz i bardzo drobno posiekaj imbir i cebulę. Czosnek przeciśnij przez praskę, natkę posiekaj.
      - Dodaj do mięsa wszystkie przyprawy i posiekane składniki. Wyrabiaj ręką co najmniej 5 minut, aż masa będzie jednolita.
      - Z masy wielkości mandarynki formuj wydłużony wałek i nadziewaj go wzdłuż na patyczek. Wyjdzie sześć dużych szaszłyków.
      - Natłuść kofty olejem, najlepiej dłońmi, poprawiając przy tym kształt.
      - Grilluj albo smaż na lekko natłuszczonej patelni 7–10 minut z każdej strony. W piekarniku piecz w 200 °C 15–20 minut, w połowie odwróć.
      - Podawaj ze świeżymi warzywami, pitą albo naanem i sosem jogurtowym.
