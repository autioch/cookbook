---
title: Ciastka owsiane
summary: 'Proste ciastka z płatków owsianych, masła i jajek, mieszane łyżką. Po wystudzeniu chrupią.'
categories: [deser, przekaska]
status: szkic
servings: 20
time: { active: 10, total: 30 }
ingredients:
  - items:
      - { name: płatki owsiane, amount: 200, unit: g, note: 'ok. 1,5 szklanki' }
      - { name: masło, amount: 100, unit: g, note: bardzo miękkie albo roztopione }
      - { name: cukier, amount: 4, unit: łyżki, note: 'ok. 60 g' }
      - { name: jajka, amount: 2, note: średnie }
      - { name: mąka pszenna, amount: 2, unit: łyżki, note: 'czubate, ok. 45 g', product: mąka }
      - { name: proszek do pieczenia, amount: 1, unit: łyżeczka, note: płaska }
      - { name: rodzynki albo żurawina, note: mała garść, product: rodzynki, optional: true }
steps:
  - items:
      - Nagrzej piekarnik do 180 °C, grzanie góra-dół.
      - W misce wymieszaj płatki, cukier, mąkę i proszek do pieczenia.
      - Wbij jajka, dodaj masło i wymieszaj łyżką. Masa będzie gęsta. Jeśli dodajesz rodzynki, wmieszaj je teraz.
      - Wyłóż blachę papierem do pieczenia. Nabieraj porcje wielkości orzecha włoskiego, formuj kulki i spłaszczaj je na papierze. Ciastka się nie rozlewają, więc nie trzeba dużych odstępów.
      - Piecz 15–20 minut, aż się zarumienią. Cieńsze ciastka są gotowe szybciej.
      - Po kilku minutach przełóż na kratkę. Zaraz po upieczeniu są miękkie, twardnieją, kiedy stygną.
