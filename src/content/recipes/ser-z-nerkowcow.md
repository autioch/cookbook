title: Ser z nerkowców
summary: 'Roślinny ser z nerkowców z żywymi kulturami, formowany w krążki i obtaczany w przyprawach. Robi się go dwie doby.'
categories: [przekaska, kolacja]
status: szkic
servings: 8
time: { active: 30, total: 1680 }
ingredients:
  - items:
      - { name: nerkowce, amount: 400, unit: g, note: 'połowa do namoczenia, połowa surowa' }
      - { name: olej kokosowy, amount: 125, unit: ml, note: płynny albo w temperaturze pokojowej }
      - { name: wrzątek, amount: 120, unit: ml, product: woda }
      - { name: sól wędzona, amount: 1, unit: łyżeczka, note: czubata, product: sól }
      - { name: płatki drożdżowe nieaktywne, amount: 2, unit: łyżki, product: płatki drożdżowe }
      - {
          name: wegańskie kultury jogurtowe,
          amount: 2,
          unit: saszetki,
          note: żywe kultury bakterii,
          product: kultury bakterii,
        }
      - { name: 'sezam, nori albo papryka', note: do obtoczenia, product: sezam, optional: true }
steps:
  - items:
      - Zalej 200 g nerkowców zimną wodą i odstaw na 4 godziny.
      - Odcedź namoczone nerkowce i włóż do malaksera razem z surowymi, płatkami drożdżowymi, solą i olejem. Miksuj. Olej zacznie się oddzielać, tak ma być.
      - Po ok. 4 minutach zacznij dolewać wrzątek. Miksuj, aż masa będzie biała, gładka i bez grudek.
      - Na koniec wmieszaj kultury bakterii. Masa będzie gęsta jak ciasto naleśnikowe.
      - Przelej do pojemnika i wstaw na noc do lodówki, aż stężeje.
      - W rękawiczkach formuj kule, spłaszczaj je i obtaczaj w przyprawach.
      - Ułóż na kratce o drobnych oczkach albo na papierze kuchennym i osuszaj w lodówce 12 godzin.
