---
title: Jajka faszerowane
summary: 'Połówki jajek na twardo z farszem z żółtek, majonezu, musztardy i szczypiorku. Na stół dla gości.'
categories: [przekaska]
status: szkic
servings: 4
time: { active: 20, total: 35 }
spice: 0
ingredients:
  - items:
      - { name: jajka, amount: 6 }
      - { name: majonez, amount: 3, unit: łyżki }
      - { name: musztarda, amount: 1, unit: łyżeczka }
      - { name: szczypiorek, amount: 2, unit: łyżki, note: posiekany }
      - { name: sól }
      - { name: pieprz }
      - { name: rzodkiewka, amount: 3, note: do ozdoby, optional: true }
steps:
  - items:
      - Włóż jajka do garnka z zimną wodą. Od zagotowania gotuj 10 minut.
      - Przełóż jajka do zimnej wody na 10 minut, potem obierz.
      - Przekrój jajka wzdłuż na pół i wyjmij żółtka do miski.
      - Rozgnieć żółtka widelcem na gładką masę. Dodaj majonez, musztardę i większość szczypiorku, dopraw solą i pieprzem.
      - Nałóż farsz łyżeczką do białek, z górką.
      - Posyp resztą szczypiorku, a na wierzchu ułóż plasterki rzodkiewki. Trzymaj w lodówce do podania.
