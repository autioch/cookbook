---
title: Pieczone jabłka z orzechami
summary: 'Jabłka nadziane orzechami, miodem i cynamonem, pieczone do miękkości. Deser na jesień i zimę.'
categories: [deser]
status: szkic
servings: 4
time: { active: 15, total: 50 }
spice: 0
ingredients:
  - items:
      - { name: jabłka, amount: 4, note: 'kwaskowate i twarde, np. szara reneta' }
      - { name: orzechy włoskie, amount: 50, unit: g, product: orzechy }
      - { name: miód, amount: 2, unit: łyżki }
      - { name: masło, amount: 20, unit: g }
      - { name: cynamon, amount: 1, unit: łyżeczka }
      - { name: rodzynki, amount: 2, unit: łyżki, optional: true }
      - { name: woda, amount: 100, unit: ml }
  - title: Do podania
    items:
      - { name: jogurt naturalny albo lody waniliowe, product: jogurt, optional: true }
steps:
  - items:
      - Nagrzej piekarnik do 180 °C.
      - Umyj jabłka. Odetnij górę z ogonkiem jako „czapkę”, a gniazdo nasienne wydrąż łyżeczką, nie przebijając dna.
      - Posiekaj orzechy i wymieszaj z miodem, cynamonem, rodzynkami i połową masła.
      - Napełnij jabłka nadzieniem, na wierzch połóż resztę masła i przykryj czapkami.
      - Ustaw jabłka w naczyniu żaroodpornym i wlej wodę na dno.
      - Piecz 25–35 minut, aż skórka zacznie pękać, a nóż wchodzi w jabłko bez oporu. Podawaj na ciepło, z jogurtem albo lodami.
