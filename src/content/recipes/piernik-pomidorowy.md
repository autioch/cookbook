---
title: Piernik pomidorowy
summary: 'Wilgotny piernik bez jajek i masła: pomidory z puszki z bananem i olejem, przekładany powidłami. Pomidorów w nim nie czuć.'
categories: [deser]
status: szkic
servings: 12
time: { active: 15, total: 65 }
ingredients:
  - title: Ciasto
    items:
      - {
          name: pomidory krojone z puszki,
          amount: 250,
          unit: ml,
          note: 'odmierzona szklanka, nie cała puszka',
          product: pomidory,
        }
      - { name: banan, amount: 1, product: banany }
      - { name: olej, amount: 125, unit: ml, note: '½ szklanki' }
      - { name: cukier trzcinowy, amount: 0.5, unit: szklanki, product: cukier }
      - { name: mąka pszenna albo orkiszowa, amount: 2, unit: szklanki, product: mąka }
      - { name: przyprawa do piernika, amount: 1.5, unit: łyżki }
      - { name: kakao, amount: 1, unit: łyżka }
      - { name: soda oczyszczona, amount: 1, unit: łyżeczka }
      - { name: proszek do pieczenia, amount: 0.5, unit: łyżeczki }
      - { name: sól, amount: 0.5, unit: łyżeczki }
  - title: Do przełożenia
    items:
      - { name: powidła śliwkowe, product: powidła }
      - { name: czekolada, note: 'roztopiona z 2 łyżkami oleju, do polania', optional: true }
steps:
  - items:
      - Nagrzej piekarnik do 180 °C. Wyłóż keksówkę (27–33 cm) papierem do pieczenia.
      - Zmiksuj w blenderze pomidory, banana, olej i cukier na gładką, gęstą masę.
      - W dużej misce wymieszaj trzepaczką mąkę, przyprawę, kakao, sodę, proszek i sól.
      - Wlej masę z blendera do suchych składników i wymieszaj łyżką na gęste ciasto.
      - Przełóż do keksówki, najwyżej do połowy wysokości, bo ciasto mocno rośnie. Piecz 45–50 minut, aż będzie złote.
      - Wystudzony piernik przekrój na pół i przełóż powidłami. Wierzch możesz polać czekoladą.
sources:

    url: https://jadlonomia.com/przepisy/piernik-pomidorowy/
---

Pomidorów krojonych nie zastępuj przecierem, passatą ani koncentratem (tak radzi źródło).
