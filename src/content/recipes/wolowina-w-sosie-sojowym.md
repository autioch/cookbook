title: Wołowina w sosie sojowym z warzywami
summary: 'Cienkie paski wołowiny smażone z papryką i cebulą, na koniec z sosem sojowym, czosnkiem i imbirem. Z jednej patelni.'
categories: [obiad]
status: szkic
servings: 4
time: { active: 25, total: 30 }
ingredients:
  - items:
      - { name: wołowina, amount: 400, unit: g, note: 'ligawa, rostbef albo udziec' }
      - { name: papryka czerwona, amount: 1, product: papryka }
      - { name: papryka zielona, amount: 1, product: papryka }
      - { name: cebula, amount: 1, note: duża }
      - { name: sos sojowy, amount: 3, unit: łyżki, note: 'do 4' }
      - { name: olej, amount: 1, unit: łyżka }
      - { name: czosnek, amount: 1, unit: ząbek, optional: true }
      - { name: imbir świeży, note: kawałek, product: imbir, optional: true }
      - { name: sezam, note: do posypania, optional: true }
      - { name: ryż albo makaron, note: do podania, product: ryż, optional: true }
steps:
  - items:
      - Oczyść wołowinę z błon i pokrój w poprzek włókien na bardzo cienkie paski.
      - Na woku albo głębokiej patelni mocno rozgrzej olej. Smaż mięso na dużym ogniu 8–10 minut, co jakiś czas mieszając.
      - W tym czasie pokrój paprykę w paski albo kawałki na jeden kęs, cebulę w piórka. Czosnek i imbir drobno posiekaj.
      - Dodaj warzywa do mięsa, zmniejsz ogień do średniego i smaż 5–7 minut, aż lekko zmiękną, ale zostaną chrupiące.
      - Wlej sos sojowy, dodaj czosnek i imbir, wymieszaj i podgrzewaj jeszcze minutę. Posyp sezamem.
