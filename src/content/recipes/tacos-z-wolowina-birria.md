title: Tacos z szarpaną wołowiną birria
summary: 'Wołowina marynowana w sosie z suszonych papryczek chili, duszona w piekarniku do miękkości i szarpana, na tortillach z cebulą, kolendrą i limonką.'
categories: [obiad]
status: szkic
servings: 4
time: { active: 45, total: 360 }
spice: 1
ingredients:
  - title: Mięso
    items:
      - { name: łopatka wołowa, amount: 600, unit: g, note: albo jagnięcina, product: wołowina }
      - { name: ocet winny, amount: 1, unit: łyżka, product: ocet }
      - { name: sól, amount: 1, unit: łyżeczka }
  - title: Sos birria adobo
    items:
      - { name: suszona papryczka ancho, amount: 1, product: suszone chili }
      - { name: suszona papryczka guajillo, amount: 1, product: suszone chili }
      - { name: suszona papryczka cascabel, amount: 1, product: suszone chili }
      - { name: suszona papryczka chipotle, amount: 1, product: suszone chili, optional: true }
      - { name: woda, amount: 250, unit: ml }
      - { name: kumin, amount: 1, unit: łyżeczka, note: kmin rzymski }
      - { name: oregano, amount: 1, unit: łyżeczka, note: najlepiej meksykańskie }
      - { name: goździki, amount: 2 }
      - { name: czosnek, amount: 1, unit: ząbek }
      - { name: cynamon, amount: 0.25, unit: łyżeczki }
      - { name: pieprz, amount: 0.25, unit: łyżeczki }
  - title: Do podania
    items:
      - { name: tortille kukurydziane, product: tortille }
      - { name: cebula biała, note: drobna kostka, product: cebula }
      - { name: kolendra, note: posiekana }
      - { name: limonka, amount: 1, note: w ćwiartkach }
      - { name: salsa roja, optional: true }
steps:
  - title: Mięso i sos
    items:
      - Pokrój mięso w duże kawałki. Wymieszaj ocet z solą, wmasuj w mięso i wstaw do lodówki.
      - Usuń pestki z papryczek. Opiecz je na suchej patelni, aż przypalą się z obu stron.
      - Zagotuj 250 ml wody, wrzuć papryczki i gotuj 5–6 minut.
      - Upraż kumin, oregano i goździki na suchej patelni przez ok. minutę.
      - Zmiksuj papryczki z wodą, uprażone przyprawy, czosnek, pieprz i cynamon na gładki, ciemny sos.
      - Zalej sosem mięso, przykryj i wstaw do lodówki na 2–12 godzin. Może stać i 48 godzin.
  - title: Pieczenie
    items:
      - Przełóż mięso z sosem do naczynia żaroodpornego i przykryj pokrywką albo folią. Piecz w 190–200 °C 2,5–3 godziny. Zaglądaj co jakiś czas i dolej wody, jeśli mięso wysycha.
      - Zdejmij przykrycie i piecz jeszcze 15 minut.
      - Rozerwij mięso widelcami i wymieszaj z sosem, w którym się dusiło.
      - Podawaj na podgrzanych tortillach, z cebulą, kolendrą i skropione limonką.
